# materials/ ― Discordで作った学習資料の置き場所

Discordで集めた資料（画像・PDF・Word・Excel・Markdown・メモなど）を、**そのまま** ここに置きます。
サイトには直接表示されません。Claude Code がここの資料を読んで、`content/` の Markdown に整理します。

## フォルダの分け方

```
materials/
├─ day001/          ← 学習ログ Day 1 の資料
│   ├─ discord-log.md       Discordのやりとり（コピペでOK）
│   ├─ chatgpt-answer.png   スクリーンショット
│   └─ memo.docx
├─ day015/          ← Day 15 の資料
├─ experiment001/   ← 実験001 の資料
└─ tools/           ← AIツールについての資料
```

- フォルダ名は `day` + 3桁の数字（`day015`）、`experiment` + 3桁の数字（`experiment002`）にそろえます。
- 個人情報（本名・メールアドレス・顔写真など）が入っていないか、置く前に確認してください。
- サイトに載せたい画像は、Claude Code が `public/images/` にコピーします。
