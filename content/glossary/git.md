## もう少しくわしく

プログラムを変更するたびに「ここまでの状態」を保存（**コミット**）しておくと、失敗しても前の状態に戻せます。
ゲームのセーブポイントのようなものです。

## AIと使うときのコツ

:::member[アプリ開発フローより]
小さく依頼して、こまめにコミット。1回の指示は1機能まで。Git で戻せる状態を保つ。
:::

:::point
GitHub は、Git の履歴をインターネット上で保存・共有できるサービスです。このサイトのデータも GitHub に保存されています。
:::
