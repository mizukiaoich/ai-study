## もう少しくわしく

ChatGPT などは、普段はWebサイトやアプリの画面から使います。
API を使うと、**自分で作ったプログラムやアプリの中から** AIを呼び出せます。

## 例

- 自分のアプリに「AIで文章を要約する機能」を付ける
- たくさんの画像をまとめてAIで作る

:::point
API はふつう **使った分だけ料金がかかる**（[従量課金](/glossary/pay-as-you-go/)）ことが多く、チャットの月額プランとは別の料金になっています。
:::
