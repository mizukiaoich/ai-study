まずは **「どんな種類のAIがあって、だいたいいくらなのか」** をざっくり知るためのページです。

:::warning[料金について]
料金は **2026年10月時点でメンバーが調べた目安** です。料金・プランはよく変わります。また、**ドル建ての料金は為替で変わり**、**スマホアプリから契約すると高くなる** ことがあります。契約する前に、必ず公式サイトで確認してください。
:::

## 生成AIは大きく3種類

| 種類 | 何をするAI？ | 代表例 |
| --- | --- | --- |
| 文章・対話AI | 質問に答える、文章を書く、相談にのる | ChatGPT、Gemini、Claude |
| 画像生成AI | 言葉（プロンプト）から絵や写真を作る | Midjourney、Adobe Firefly |
| 動画・音声・コードのAI | 動画を作る、声を作る、プログラムを書く | Runway、ElevenLabs、GitHub Copilot |

:::point
最近は1つのAIで「文章も画像も音声も」扱えるものが増えています（例：ChatGPT や Gemini は画像も作れます）。種類の境目は、だんだんあいまいになってきています。
:::

## 文章・対話AI

| 名前 | 提供 | 主な用途 | 無料 | 有料の目安（メンバー調べ） |
| --- | --- | --- | --- | --- |
| [ChatGPT](/tools/chatgpt/) | OpenAI | 文章・相談・コード・画像 | あり | 月1,400円〜 |
| [Gemini](/tools/gemini/) | Google | 文章・検索・Googleのサービスとの連携 | あり | 月725円〜 |
| [Claude](/tools/claude/) | Anthropic | 長い文章を読む・文章を書く・コード | あり | 有料プランあり |
| [Grok](/tools/grok/) | xAI | 対話・X（旧Twitter）との連携 | 無料枠あり | 月980円〜 |
| [Copilot](/tools/copilot/) | Microsoft | Office（Word・Excelなど）との連携・検索 | あり | Microsoft 365 向けの有料版あり |
| [Perplexity](/tools/perplexity/) | Perplexity | 出典（情報の元のページ）つきのAI検索 | あり | 有料プランあり |

### 補足（サイト更新時に追記）

- **ChatGPT**：月1,400円は、いちばん安い有料プラン「Go」の値段のようです。よく名前を聞く「Plus」は月3,000円前後という記事が多くありました。
- **Gemini**：月725円は「Google AI Plus」というプランで、Googleドライブなどの保存容量もセットになっているそうです。上位プランの「Google AI Pro」は月2,900円という記事がありました。
- **Grok**：月980円は X（旧Twitter）の有料プラン「X Premium」の値段で、Grokを多めに使える特典がついています。Grok専用の「SuperGrok」は月30ドル前後という記事が多く、**どちらで契約するかで値段がかなり違います**。

:::official[Claude の料金（公式サイトで確認）]
Claude の公式料金ページでは、個人向けに **Free（無料）**、**Pro（月20ドル。年払いなら月17ドル相当）**、**Max（月100ドル〜）** がありました。Pro 以上には、後で出てくる **Claude Code** も含まれています。（2026年10月8日に確認）
:::

:::point[名前がまぎらわしいもの]
**Copilot（Microsoft Copilot）** と、プログラミング用の **GitHub Copilot** は別のサービスです。どちらも Microsoft のグループが提供していますが、使う目的が違います。
:::

## 画像生成AI

| 名前 | 主な用途 | 無料 | 有料の目安（メンバー調べ） |
| --- | --- | --- | --- |
| Midjourney | 高品質なアート・イラスト | なし（有料のみ） | 月10ドル〜 |
| Stable Diffusion | 自分好みにカスタマイズできる | 自分のPCで動かせば無料 | APIは[従量課金](/glossary/pay-as-you-go/) |
| Adobe Firefly | 仕事（商用）向けの画像生成・編集 | 毎月の無料枠あり | 月4.99ドル〜 |
| DALL·E | 文章から画像を作る | ― | [API](/glossary/api/)の従量課金（1枚0.04ドル〜） |

### 補足（サイト更新時に追記）

:::warning[DALL·E は終了している可能性があります]
Web記事を調べたところ、**DALL·E 3 の API は2026年5月に提供が終わり**、後継の「GPT Image」という画像生成モデルに切り替わった、という記事が複数ありました。ChatGPT の中の画像生成も、すでに新しいモデルになっているようです。
ただし、OpenAI の公式ページはまだ確認できていません。
:::

- **Midjourney**：月10ドルの「Basic」プランが一番安いという点は、複数の記事で一致していました。無料で試す方法は今のところないようです。
- **Stable Diffusion**：自分のPCで無料で動かせますが、**性能の高いグラフィックボード（GPU）が必要** です。初心者には少しハードルが高めです。
- **Adobe Firefly**：有料プランの値段が、記事によって「4.99ドル」と「9.99ドル」に分かれていました。公式サイトで確認が必要です。

## 動画・音声・コードのAI

| 名前 | 主な用途 | 無料/有料の目安（メンバー調べ） |
| --- | --- | --- |
| Runway / Sora | 動画生成 | 多くは有料・クレジット制 |
| ElevenLabs | 音声合成・ナレーション | 無料枠あり、本格的に使うなら有料 |
| GitHub Copilot / Cursor / [Claude Code](/tools/claude-code/) | プログラミングの手伝い | 無料枠と有料が混在 |

### 補足（サイト更新時に追記）

- **クレジット制** とは、先に「ポイント（クレジット）」を買ったり毎月もらったりして、1回作るごとにポイントを消費するしくみです。動画は1本作るのに多くのクレジットを使うことが多いです。
- **Claude Code** は、Claude の Pro プラン（月20ドル）以上に含まれています（公式サイトで確認）。このサイトの更新にも使っています。
- 表にはありませんが、**音楽を作るAI**（例：Suno）や、**自分の資料をもとに答えてくれるAI**（例：[NotebookLM](/tools/notebooklm/)）もあります。

## その他のサービス（Day 5 で追加）

[Day 5](/learning/day005/) で、上の表にのっていなかったサービスも調べました。

| 種類 | 主なサービス | ひとこと（サイト更新時に追記） |
| --- | --- | --- |
| 文章 | DeepSeek、Mistral、Llama（Meta）など | 中身（モデル）が公開されているものが多く、[ローカルLLM](/glossary/local-llm/) としても使われる（[オープンソース](/glossary/open-source/)） |
| 音楽 | Suno、Udio など | 歌詞やイメージを伝えると、歌や曲を作ってくれる |
| 画像・デザイン | Canva のAI機能、Leonardo.Ai など | デザインツールの中で、画像生成や文字入れができる |
| 議事録・文字起こし | Notta、Otter.ai など | 会議の音声を文字にして、要約までしてくれる |

:::warning
- 音楽や画像のAIで作ったものを仕事やSNSで使うときは、サービスごとの **利用規約（商用利用できるか）** を確認しましょう（[著作権・学習データ問題](/glossary/copyright-training-data/)）。
- 議事録AIに会議の音声を読ませるときは、**参加者の同意** や、社外秘の情報を入れていいかに注意が必要です。
- 中国の会社が提供している DeepSeek など、サービスによって **データの保存場所や扱い** がちがいます。個人情報や仕事の情報を入れる前に、プライバシーポリシーを確認しましょう。
:::

## 目安：どう始めればいい？

:::member
まずは **無料で試してみて**、足りなくなったら **月1,000円前後の有料プラン** を考えるのがよさそう。
:::

- 無料版でも、普段の質問や文章作成なら十分なことが多い
- 有料にする前に「何に使いたいか」を決めると、選びやすい
- 料金は変わるので、**契約前に公式サイトを確認する**

- DALL·E の終了と、後継モデルについての公式の情報
