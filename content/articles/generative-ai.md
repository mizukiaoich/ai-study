## 1. 生成AIとは

:::member[Day 6 のまとめより]
生成AI（Generative AI）は、大量のデータから学習したパターンをもとに、文章・画像・音声・動画・コードなどを **新しく作り出す** AIです。
人が **普通の言葉で指示を出すだけ** で使えるのが特徴です。
:::

:::point
「普通の言葉で指示を出すだけで使える」のは、とても大きな変化です。それまでのAIを使うには、プログラミングやデータの準備が必要なことがほとんどでした。この指示の文章を [プロンプト](/glossary/prompt/) と呼びます。
:::

## 2. 従来のAIとのちがい

| | 従来のAI（識別・予測型） | 生成AI |
| --- | --- | --- |
| 役割 | 分類する・判定する・予測する | 新しいものを作る |
| 例 | 迷惑メール判定、画像の犬／猫の判別、売れ行きの予測 | 文章作成、イラスト作成、コード作成 |
| 入力 | 決まった形式のデータ | 普通の言葉による指示（[プロンプト](/glossary/prompt/)） |
| 用途 | 特定の1つの作業向け | 1つで幅広い用途に対応 |

:::point[補足]
従来のAIがなくなったわけではありません。スマホの顔認証や迷惑メールの振り分けなど、今も身の回りでたくさん使われています。生成AIは「AIの中の新しい仲間」です（[AIとは何か？](/articles/ai-basics/)）。
:::

## 3. しくみ

### 文章を作るAI（LLM）

1. 大量の文章を読み込み、「この言葉の次に来やすい言葉」のパターンを覚える（[学習](/glossary/training/)）
2. 指示を受けると、ふさわしい続きの言葉を **1つずつ選んでつなげる**（[推論](/glossary/inference/)）

この処理の土台になっているのが、2017年に発表された [Transformer](/glossary/transformer/) という技術です（くわしくは [LLMとは？](/articles/llm/)）。
文章は [トークン](/glossary/token/) という小さな単位に区切って処理されます。

:::point[補足：なぜ毎回ちがう答えになるの？]
次の言葉を選ぶとき、いちばん確率が高い言葉だけでなく、少しランダムに選ぶようになっています。そのため、同じ質問でも毎回少しちがう答えが返ってきます（[温度](/glossary/temperature/)）。[Day 1](/learning/day001/) で気づいたことの答えのひとつです。
:::

### 画像を作るAI

多くは [拡散モデル](/glossary/diffusion-model/) というしくみを使います。ノイズだらけの画像から少しずつノイズを取り除き、指示に合った絵に仕上げていきます。

### 切り貼りではない……けれど

:::member[Day 6 のまとめより]
どちらも、学習データを切り貼りしているわけではなく、学んだパターンから新しく作っています。
:::

:::warning[補足：ただし例外もある]
基本的には「パターンから新しく作る」ものですが、研究では、**学習データの文章をほぼそのまま再現してしまう（記憶してしまう）ことがある** と報告されています。新聞記事や歌詞がそのまま出てきたとして、裁判になっている例もあります。
そのため、AIが作ったものが **既存の作品とそっくりになっていないか** 確認することが大切です（[著作権・学習データ問題](/glossary/copyright-training-data/)）。
:::

## 4. かんたんな歴史

| 年 | できごと |
| --- | --- |
| 2014年 | [GAN](/glossary/gan/)（敵対的生成ネットワーク）が登場し、画像生成が進歩 |
| 2017年 | [Transformer](/glossary/transformer/) が発表され、今の言語AIの土台に |
| 2020年前後 | GPT-3 など、[大規模言語モデル（LLM）](/glossary/llm/) が話題に |
| 2022年 | Stable Diffusion、Midjourney などの画像生成AIが一般に広がる。年末（11月30日）に ChatGPT が登場し、一気に普及 |
| 現在 | 文章・画像・音声・動画をまとめて扱う [マルチモーダル](/glossary/multimodal/) 化と、自分で作業を進める [AIエージェント](/glossary/ai-agent/) 化が進行中 |

:::point[補足：どれくらい一気に広まった？]
ChatGPT は、公開からわずか2か月ほどで月間の利用者が約1億人に達したと推計され、「史上最速で広まったアプリ」と報じられました（2023年2月の報道）。
:::

:::point[補足：最近の流れ]
- 答える前にじっくり考える [推論モデル](/glossary/reasoning-model/) が登場
- AIと外部のツールをつなぐ共通ルール [MCP](/glossary/mcp/) が広がる
- 中身を公開した [オープンソース](/glossary/open-source/) のモデルも増え、[ローカルLLM](/glossary/local-llm/) として自分のPCで動かす人も
:::

## 5. できること

| 分野 | できること |
| --- | --- |
| 文章 | 下書き、要約、翻訳、添削、アイデア出し |
| 画像 | イラスト、デザイン案、写真の加工 |
| 音声・音楽 | ナレーション、作曲、文字起こし |
| 動画 | 短い映像や広告素材の生成 |
| コード | プログラムの作成、バグ修正、解説 |
| 調べもの | 資料の整理、質問への回答 |

どのAIで何ができるかは [主な生成AIまとめ](/articles/ai-types-overview/) にまとめています。

## 6. 弱点とリスク

| 弱点・リスク | 内容 | 対策（補足） |
| --- | --- | --- |
| [ハルシネーション](/glossary/hallucination/) | もっともらしい嘘を出すことがある | 大事なことは出典で確認する |
| 情報が古い | 学習した時点までの知識が中心（[ナレッジカットオフ](/glossary/knowledge-cutoff/)） | 検索機能つきのAIを使う、日付を確認する |
| 著作権・権利 | 学習データや作ったものの扱いをめぐる議論が続いている | 利用規約を確認、既存作品との類似に注意 |
| 情報漏えい | 入力した内容の扱いに注意が必要（仕事の機密など） | 機密は入力しない、学習に使わない設定を確認 |
| 偏り（[バイアス](/glossary/bias/)） | 学習データの偏りが回答に出ることがある | 「ほかの見方は？」と聞く、複数の情報を見比べる |
| 悪用 | [ディープフェイク](/glossary/deepfake/) や詐欺の文面づくりなど | 本物そっくりでも、一度立ち止まって確かめる |

:::point[補足：入力した内容は学習に使われる？]
サービスによっては、入力した内容がAIの改善（学習）に使われることがあります。多くのサービスには **「学習に使わない」ように選べる設定** があります（設定の名前や場所はサービスごとにちがいます）。仕事で使う場合は、会社のルールも確認しましょう。
:::

:::official[著作権についての国の考え方]
文化庁は2024年3月に「AIと著作権に関する考え方について」をまとめています。AIの話を「学習するとき」と「作ったものを使うとき」に分けて考えることなどが整理されています（法的な拘束力はないとされています）。
:::

## 7. 付き合い方のコツ

:::member[Day 6 のまとめより]
- 下書きや発想の補助として使い、**最終判断は自分で行う**
- 事実や数字は、重要なものほど **出典で確認する**
- 指示は **具体的に書く**（目的、相手、形式、分量など）
- 個人情報や機密情報は入力しない、または設定を確認する
:::

:::point[補足：指示を具体的に書く例]
- ✕「メールを書いて」
- ○「取引先に、打ち合わせの日程変更をお願いするメールを書いて。丁寧な敬語で、200字くらい。候補日は10月20日と21日」

くわしくは [プロンプトエンジニアリング](/glossary/prompt-engineering/) を見てください。
:::
