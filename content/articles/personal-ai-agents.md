## 1. Muse とは

:::official[Meta の発表より]
Muse（ミューズ）は、Meta が開発した **パーソナルAIエージェント** です。2026年9月8日に米国で発表され、**10月23日に日本で提供が始まりました**（北米以外では初めて）。iOS・Android のアプリと Web（muse.ai）で使えて、基本機能の多くは無料です。
:::

ふつうのチャットAIが「質問に答える・文章を作る」ことが中心なのに対して、Muse は **ユーザーの代わりに、いくつものサービスを使って実際に作業を進める** ことを重視しています（[AIエージェント](/glossary/ai-agent/)）。

| | ふつうのチャットAI | Muse のようなAIエージェント |
| --- | --- | --- |
| AIがすること | 調べる・考える・文章を作る | 調べる・計画する・**操作する** |
| 人がすること | 結果を受け取って、自分で作業を進める | 大事な判断と最終確認 |

:::ai[ChatGPT の資料より]
たとえば「来月の旅行を計画して」と伝えると、希望条件の整理、交通手段や宿泊施設の調査・比較、予約手続きの補助までを一連の仕事として進めます。AIを「質問する道具」から「仕事を任せる相手」に変えるサービスです。
:::

:::point[補足]
- 「世界初のパーソナルAIエージェント」は Meta の宣伝での表現です。似たサービスはほかにもあります（→ 7. 比較）。
- ChatGPT や Claude にも、作業を進めるAIエージェントの機能があります。Muse だけが特別というわけではありません。
- Meta が作っているので、Instagram・Facebook・WhatsApp と同じ会社です。
:::

## 2. Muse でできること

| 分野 | 具体的な作業の例 |
| --- | --- |
| 情報収集 | いくつものサイトを見て回り、商品・料金・サービスを比較 |
| メール管理 | 大事なメールの確認、返信案の作成、承認したあとの送信 |
| スケジュール | Google カレンダーと連携して、予定の整理・調整 |
| 旅行 | 行き先選び、交通・ホテルの比較、予約手続きの補助 |
| 買い物 | 商品選び、価格比較、カートへの追加、購入前の確認 |
| SNS | Instagram で保存した情報を使った提案 |
| 事務作業 | ブラウザ操作、フォーム入力、情報整理 |
| 長い作業 | 目標を立てて計画に分け、何段階もの作業を実行。アプリを閉じても作業を続け、必要なときに通知 |
| 文書作成 | 調べた結果のまとめ、資料・計画書の作成 |

:::warning
これらは公開されている対応分野や例です。すべてのサイト・アカウント・地域で同じようにできるわけではありません。ログイン・本人確認・支払い・サイト側の制限で、途中で止まることもあります。
:::

## 4. メリットとリスク（使う人から見て）

| メリット | リスク |
| --- | --- |
| 何サイトも行き来する **手間が減る** | 便利に使うほど、メール・予定・購入履歴などの **個人情報を渡す** ことになる |
| プログラミングなしで、**ふつうの文章で頼める** | 間違った答えだけでなく、**誤送信・誤予約など現実のトラブル** につながりうる |
| アプリを閉じても **作業を続けてくれる** | ログイン・本人確認・支払いなどで **途中で止まる** ことがある |
| 過去の会話や好みを **覚えて** くれる | 作ったものの数字や条件は、**最後に人が確認** する必要がある |
| **無料から** 試せる | たくさん使うには有料プランが必要になる |

:::point[補足：どこまで任せる？]
AIエージェントを使うときは、「何ができるか」だけでなく **「どこまで任せてよいか」** を考えることが大事です。最初は、AIに与える権限を必要最小限にするのが基本です（[最小権限](/glossary/least-privilege/)）。
:::

## 5. 人気は本物？

:::point[データ（調査会社 Sensor Tower の推計・2026年10月の報道。Meta の公式発表ではありません）]
- 公開から約40日で **米国だけで約1,020万ダウンロード**（世界で約1,090万）。この速さで1,000万を超えたアプリは、これまで12個しかなく、ゲーム以外では2023年の Threads 以来
- 1日の利用者数：約250万人（10月16日時点）
- 米国での [継続率](/glossary/retention-rate/)：Muse は **7日後30%・14日後23%**。ChatGPT・Claude・Grok の平均は7日後19%・14日後16%
- ただし、Meta の10月の広告費の **約39%が Muse の宣伝** に使われたと推計されている（9月は約23%）
:::

:::member[メンバーで考えたいポイント]
急に広まったのは事実。でも、たくさん広告を出した効果も大きいので、**「製品が良いから広まった」とだけは言えない**。また、どれも「推計」で、ダウンロード数と使い続けている人の数はちがう。
:::

## 6. このブームは続く？

:::ai[ChatGPT の予想（あくまでAIの意見）]
Muse の話題性は落ち着く可能性がある一方、**AIエージェントの市場そのものは広がり続ける** 可能性が高い、という予想でした。理由は次の3つです。

1. AIの競争が「答えの正確さ」から「**どれだけ作業を終わらせられるか**」に変わってきている
2. OpenAI・Anthropic・Google など大手も同じ分野に参入している
3. 最後の購入・予約・操作で止まるなど、まだ課題も多い

今後は「30日・90日後の継続率」「有料契約の割合」「実際に作業を終えられた割合」「広告への依存度」を見るべき、としています。
:::

| シナリオ | 起こる条件 |
| --- | --- |
| 急成長が続く | 毎日作業を任せる人が増え、使い続ける人が増える |
| 話題は落ち着き、定着する | 宣伝の効果は薄れるが、一定の利用者が残る |
| 成長が急に止まる | 誤操作・プライバシーの不安・他社との差がないことが目立つ |

:::question
登場から約7週間なので、どうなるかはまだ分からない。このサイトで、しばらく後にもう一度調べてみたい。
:::

## 7. 似ているAIエージェントとの比較

| サービス | 会社 | 得意なこと | Muse とのちがい |
| --- | --- | --- | --- |
| [Muse](/tools/muse/) | Meta | 日常生活、買い物、予約、個人の作業 | 無料から使える生活密着型 |
| OpenAI dots | OpenAI | ずっと動き続ける個人向けの支援、何段階もの自動化 | 使えるプランや地域に制限がある |
| ChatGPT Work | OpenAI | 調査、データ分析、資料づくり | 表・スライド・文書など「完成した成果物」に強い |
| Claude Cowork | Anthropic | PC作業、ファイル処理、ビジネス文書 | 自分のPCのファイルやデスクトップでの作業を重視 |
| Gemini 系のエージェント | Google | Google のサービス、予定、日常の支援 | Google のサービスとのつながりが強み |
| OpenClaw | オープンソース | 自分好みに作りこめるエージェント | 自分のPCで動かす。技術的な知識と、セキュリティの管理が必要 |

:::warning
これは「主な使い道」の比較で、性能のランキングではありません。どのサービスも、使える地域・料金・できること・使えるモデルがちがいます。
:::

:::point[使い分けの考え方]
- 日常の買い物・旅行・生活の細かい作業 → Muse が候補
- レポート・表・スライドなどの完成物がほしい → ChatGPT Work や Claude Cowork
- 普段から Google のサービス中心 → Gemini も比較の対象に

大事なのは「どのAIが一番かしこいか」より、**自分が使っているサービスとつながって、何を実行できるか** です。
:::

## 8. プライバシーとセキュリティ

:::official[Meta の発表・解説より：安全のしくみ]
- 利用者ごとに分けられた専用の仮想コンピューター（**Secure VM**）の中で動く
- AIとは別の見張り役「**Sentinel**」が、インターネットへのアクセスを管理する。メールの送信や買い物など大事な操作の前には、本人の承認を求める
- 会話を Meta のAIの学習に使わないように設定できる
- Meta 自身も「Muse は間違えることがある」「[プロンプトインジェクション](/glossary/prompt-injection/) はまだ解決していない課題」としている
:::

:::warning[実際に起きた問題（2026年10月の報道）]
- **共有リンクの問題**：会話を共有したときのアドレスが、インターネット上の公開記録（DNS）から見つけられる作りになっていた。セキュリティ会社が約6,800件の共有リンクを見つけ、会議の予定・融資の申し込み・会社の内部資料などが見られる例を確認した。Meta は **共有機能を一時停止** した。
- 第三者のテストでは、購入手続きの途中で止まった例や、作った資料に間違った数字が入っていた例も報告されている。
:::

:::point[安全に使うために]
- 最初は **情報収集や比較など、失敗しても困らない作業** から始める
- 支払い・外部へのメール送信・銀行や個人情報を使う操作は、慎重に
- AIに与える権限は **最小限** にする（[最小権限](/glossary/least-privilege/)）
- 会話の「共有」機能は、中身を確認してから使う。仕事の情報や個人情報が入った会話は共有しない
- 学習に使われたくない場合は、設定を確認する
:::

## 9. まとめ

Muse は、AIエージェントをぐっと身近にするかもしれないサービスです。最初の広まり方はとても大きく、無料から使えることと、Meta の利用者の多さが強みです。
一方で、使い続ける人がどれだけいるか、誤操作をどう防ぐか、個人情報をどう守るか、他社とのちがいは、まだこれから評価されるところです。

**今回いちばん大事なポイントは、Muse の人気そのものより、AIが「答えを作る」段階から「現実の作業を進める」段階へ進んでいること** です。

### 試してみるなら

:::point[比較実験のアイデア]
同じ課題を Muse・ChatGPT Work・Claude Cowork などに頼んで、**正確さ・最後までできたか・かかった時間・人が直した回数** を比べると勉強になりそうです。

例：「11月の土日に、横浜から家族5人で1泊2日の旅行を計画。予算8万円以内で、移動時間・宿泊先・食事・子ども向けの施設を比べて、予約の手前まで準備してください。」

（実際の予約や支払いは、AIに任せずに人がやりましょう）
:::
