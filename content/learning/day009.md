# 今日の課題

10月23日に日本で使えるようになった Meta の「Muse」が、**どんなAIで、何ができて、何に気をつけるべきか** を知る。

## 調査したこと

ChatGPT に「Muse を徹底解説して」と頼んで、資料にまとめてもらった。内容は次のとおり。

1. Muse とは（ふつうのチャットAIとのちがい）
2. できること・日本で使える連携サービス
3. 料金
4. メリットとリスク
5. 人気は本物か（ダウンロード数・継続率・広告費）
6. ブームは続くか（ChatGPT の予想）
7. 似ているAIエージェントとの比較
8. プライバシーとセキュリティ

くわしくは記事 [MetaのAIエージェント「Muse」とは？](/articles/personal-ai-agents/) にまとめた。

## Discordで出た疑問

- Muse は ChatGPT と何がちがうの？
- 人気は本物？ それとも宣伝のおかげ？
- 個人情報をわたしても大丈夫？

## 実際に試したこと

:::tried[AIの資料をファクトチェックしてみた]
今回の資料は **AI（ChatGPT）の回答** だったので、サイトに載せる前に、主な内容をニュースや Meta の公式発表で確認した。

- 日本での提供開始日、料金、ダウンロード数、継続率、広告費、共有リンクの問題などは、**ほぼすべて報道や公式発表と一致** していた
- ただし「会話の学習利用が **初期状態で有効**」という点は、**確認できなかった**（学習に使わない設定があることは確認できた）

AIの調べものは、かなり正確なこともあるけれど、**全部が正しいとは限らない**。1つずつ確かめるのが大事だと分かった。
:::

:::question
Muse そのものは、まだ誰も使っていない。

## 分かったこと

- Muse は **「答えるAI」ではなく「作業するAI」**（[AIエージェント](/glossary/ai-agent/)）。メール・予定・旅行・買い物などを代わりに進める。
- 2026年9月に米国、**10月23日に日本** で提供開始。基本は無料、有料は月2,799円〜（国内報道）。
- 米国では約40日で1,000万ダウンロード。[継続率](/glossary/retention-rate/)も他のAIアプリより高い。ただし **Meta の広告費の約39%が宣伝に使われていた**（推計）。
- 便利なぶん、**個人情報やアカウントの権限をわたす** ことになる。実際に、共有リンクから会話が見つけられる問題も起きた。
- 似たAIエージェントは、OpenAI・Anthropic・Google などからも出ている。比べるときは「性能」より「何とつながって、何ができるか」。

:::point[サイト更新時に追記した補足]
- Muse の安全のしくみ（Secure VM と Sentinel）は、外からの悪い指示（[プロンプトインジェクション](/glossary/prompt-injection/)）対策でもある。Meta 自身も「まだ解決していない課題」としている。
- AIエージェントを使うときは、権限を必要最小限にするのが基本（[最小権限](/glossary/least-privilege/)）。
- 「Muse AI」という同じ名前の別サービスもある。Meta のものは muse.ai。
- 用語集に [プロンプトインジェクション](/glossary/prompt-injection/)、[最小権限](/glossary/least-privilege/)、[継続率（リテンション）](/glossary/retention-rate/) を追加した。
:::

## 分からなかったこと

- 会話の学習利用は、最初の状態でオンなのか、オフなのか？（アプリで確認したい）
- 日本の連携サービス（メルカリなど）は、いつ使えるようになるのか？

:::

## 今日の結論

Muse は、AIが **「答えを作る」から「作業を進める」へ** 変わってきていることを象徴するサービス。
ただ、作業を任せるほど個人情報や権限をわたすことになるので、**低リスクな作業から、権限は最小限で** 試すのがよさそう。
そして、**AIに調べてもらった内容も、確かめてから使う**。

## 次回への課題

- 無料版で、低リスクな作業（情報収集・比較）を3つ試してみる
- 同じ課題（旅行計画など）を Muse・ChatGPT・Claude にやらせて比べる（AI実験室）
- 学習利用の初期設定を、アプリで確認する
