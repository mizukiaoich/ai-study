# 今日の課題

ChatGPT や Claude の中心にある **LLM** が、どうやって文章を作っているのかを説明できるようにする。
（[Day 6](/learning/day006/) の「生成AIとは」の続き）

## 調査したこと

次の7つの観点でまとめた。くわしくは記事 [LLMとは？](/articles/llm/) に整理した。

1. LLMとは（Large・Language・Model の意味、生成AIとの関係）
2. 文章を作るまでの流れ（トークン → 数値 → 文脈 → 予測 → くり返し）
3. 学習の段階（事前学習 → 追加の調整 → 人間のフィードバック）
4. 「大規模」の意味（パラメータ・データ・計算資源）
5. モデルの種類（大きい・小さい・推論・オープン・クローズド）
6. 限界と注意点
7. 今の広がり（RAG・ツール連携・AIエージェント・マルチモーダル）

## Discordで出た疑問

- LLM と ChatGPT は同じもの？
- 「次の言葉を予測するだけ」で、どうして会話ができるの？
- LLM は本当に意味を理解しているの？

## 実際に試したこと

:::question
今日はしくみを調べるのが中心で、新しく試したことはない。
「計算が苦手なことがある」「文字を数えるのが苦手なことがある」は、実際に試せそうなので AI実験室でやってみたい。
:::

## 分かったこと

- LLM は **生成AIの一種** で、文章を担当する部分。ChatGPT などは「LLM ＋ 使いやすい画面や機能」。
- 文章は [トークン](/glossary/token/) に分けられ、数値（[エンベディング](/glossary/embedding/)）に変えられ、[アテンション](/glossary/attention/) で文脈を読んで、次の1トークンを予測する。これをくり返す。
- 学習は **[事前学習](/glossary/pre-training/) → [追加の調整](/glossary/instruction-tuning/) → 人間のフィードバック（[RLHF](/glossary/rlhf/)）** の3段階。事前学習だけでは、質問に上手に答えられない。
- 大きいモデルは賢いけど遅くて高い。小さいモデルは速くて安い。目的で使い分ける。
- 限界：ハルシネーション、知識の期限、記憶の幅、計算、中身が見えにくい（[ブラックボックス](/glossary/black-box/)）。

:::point[サイト更新時に追記した補足]
- **答えが1文字ずつ流れるように出るのは**、1トークンずつ予測して足していくしくみをそのまま見せているから。
- **毎回答えがちがうのは**、次のトークンを少しランダムに選んでいるから（[温度](/glossary/temperature/)）。
- **文字を数える問題が苦手** なことがある：文字ではなくトークンのかたまりで見ているため（最近はかなり改善）。
- **推論モデル** は、答えを自動で確かめられる問題をたくさん解かせて、考え方を鍛える学習もしていると言われている。
- **計算が苦手** なのは、計算ツールと組み合わせる（[ツール連携](/glossary/tool-use/)）ことで補える。
- 用語集に [注意機構（アテンション）](/glossary/attention/)、[事前学習](/glossary/pre-training/)、[追加の調整（インストラクションチューニング）](/glossary/instruction-tuning/)、[ツール連携](/glossary/tool-use/)、[ブラックボックス](/glossary/black-box/) を追加した。
:::

## 分からなかったこと

:::question
- 「次の言葉を予測しているだけ」なのに、なぜ論理的な文章が書けるのか？
- どこからが「理解している」と言えるのか？
- AIの中身を説明できるようにする研究は、どこまで進んでいるのか？
:::

## 今日の結論

LLM は「次の言葉を予測する」ことを、ものすごい規模でくり返し学習したAI。
だから文章づくりはとても得意だけど、**正しさは保証されていない**。しくみを知ると、「確かめながら使う」大切さがよく分かる。

## 次回への課題

- 計算や文字数を数える問題を、いくつかのAIで試して比べる（AI実験室）
- 同じ質問を何回かして、答えの変わり方を見る（温度の体験）
