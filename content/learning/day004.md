# 今日の課題

ChatGPT・Claude・Gemini 以外にどんな生成AIがあるのかを知り、**種類・用途・料金** をざっくりつかむ。

## 調査したこと

メンバーが調べた結果を、1枚の表にまとめた。

![主な生成AIまとめ（名前・主な用途・無料/有料）](/images/learning/day004-ai-types-summary.webp)

- **文章・対話AI**：ChatGPT、Gemini、Claude、Grok、Copilot、Perplexity
- **画像生成AI**：Midjourney、Stable Diffusion、Adobe Firefly、DALL·E
- **動画・音声・コードのAI**：Runway / Sora、ElevenLabs、GitHub Copilot、Cursor、Claude Code

くわしい表は記事 [主な生成AIまとめ](/articles/ai-types-overview/) にまとめた。

## Discordで出た疑問

- AIの種類が多すぎて、どれを使えばいいか分からない
- 有料プランにする必要はあるの？

## 実際に試したこと

:::question
今日は「調べる」が中心で、表にあるAIを全部は試していない。実際に使った結果は、これから AI実験室 に記録していく。
:::

## 分かったこと

- 生成AIは、大きく **文章・対話**、**画像**、**動画・音声・コード** に分けられる。
- 文章・対話AIの多くは **無料で始められる**。
- 料金の形はいろいろある：**月額（サブスク）**、**使った分だけ払う（[従量課金](/glossary/pay-as-you-go/)）**、**ポイントを消費する（クレジット制）**。
- 同じAIでも、**どのプランか・どこで契約するか**（Web／スマホアプリ）で値段が変わる。

:::point[サイト更新時に追記した補足]
- ChatGPT の「月1,400円〜」は一番安い Go プラン。よく聞く Plus は月3,000円前後という記事が多かった。
- Grok の「月980円〜」は X（旧Twitter）の有料プラン「X Premium」の値段。
- **DALL·E 3 の API は2026年5月に終了した** という記事が複数あった（公式ページは未確認）。
- Claude の料金は公式サイトで確認できた（Pro 月20ドル〜、Claude Code も含まれる）。
:::

## 分からなかったこと

:::question
- 無料版と有料版で、実際の使い心地はどれくらい違う？
- 画像生成AIで作った画像を、SNSや仕事で使ってもいいの？（著作権・商用利用）
- Adobe Firefly の有料プランの正しい値段（記事によって違った）
:::

## 今日の結論

AIの種類はたくさんあるけれど、**まずは無料で試して、足りなければ月1,000円前後の有料プラン** を考えるのがよさそう。
料金はよく変わるので、**契約前に公式サイトで確認する**。

## 次回への課題

- 無料版と有料版の違いを、実際に使って比べてみる
- 画像生成AIを1つ選んで、実際に画像を作ってみる
- 画像生成AIの著作権・商用利用について調べる
